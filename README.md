# Quiz001 — Authorized Quiz Test Assistant

Source scaffold only; not a built APK. Intended for your own app or an app you are authorized to test.

Includes a basic Kotlin UI, provider selection, answer-validation contract, and GitHub Actions debug APK workflow. The AI provider adapters are placeholders and do not call real APIs. It does not capture another app's screen or automatically tap answers. Main-device Accessibility permission does not automatically access a separate Virtual Master guest. This project has not yet been compiled or device-tested.
